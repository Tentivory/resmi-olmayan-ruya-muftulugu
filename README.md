# Resmi Olmayan Rüya Müftülüğü

> Bu depo bir şeri daire değildir. Bu depo bir API de değildir.  
> Bu depo, gece 03:17'de uyanıp "acaba o diş ne anlama geliyordu" diyen insanlık için açılmış bir sanal gişedir.

## Bu şey ne işe yarar?

Rüyanı yazarsın. Program, müftülük koridoru akustğiyle cevap verir.  
Bilimsel makale üretmez. Tez yazmaz. Sadece **çalışır** ve biraz da kıvırır.

```bash
python3 ruya_muftusu.py "uçuyordum sonra dişim düştü tren kaçtı"
```

Çıktı örneği: dosya numarası, heyet görüşü, sembol tahlili, damga.

## Kurulum

Python 3 yeter. pip yok, framework yok, mikroservis yok.
